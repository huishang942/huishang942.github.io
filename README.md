# huishang942.github.io

HuiShang 的个人主页，使用原生 HTML、CSS 与 JavaScript 构建，无构建步骤。

## 本地预览

```bash
python -m http.server 8000
```

然后访问 http://127.0.0.1:8000/

## 部署

推送到 `main` 分支后，由 GitHub Pages 自动发布。

## 目录

- `index.html`：页面骨架
- `content.js`：站点内容配置（姓名、简介、作品、文章、联系方式）
- `app.js`：页面渲染与交互
- `assets/`：样式、字体与图标
